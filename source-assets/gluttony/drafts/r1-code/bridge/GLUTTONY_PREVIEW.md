## 試玩與範圍

[gluttony-preview.html](gluttony-preview.html)可直接開始完整暴食，另有五外貌、五個遊戲、三招×三階段、兩處決、最終爆發及九個插圖入口，共 32 個。主遊戲與正式卡帶沒有新增測試入口；現有四罪的設定、通關、解鎖及排行榜不變。此頁只讀 `bridge-settings`，切換設定只留當前頁面，程式沒有正式存檔寫入。

本地可攜交付位於 `/workspace/artifacts/gluttony-preview-r1/`：單一 `gluttony-r1-playable.html`，以及 `gluttony-r1-preview.zip` 中的 `local-preview/`。ZIP 不重複裝入單一 HTML。資料夾版在該資料夾執行 `python start.py`，只開本機 HTTP。這些是本地交付，**沒有公開可玩網址**；不能把環境 localhost 或工作區路徑當成 Pages 發布。

## 流程與玩法

| 階段 | Normal／Hard HP（內部值） | 流程 |
| --- | --- | --- |
| 廚師／飢餓廚師 | 560／560 | 原 Bridge、五款遊戲及三招攻擊輪替；五款都結束一次後才能真正歸零 |
| 巨口／膨脹巨口 | 700／840 | 20% 鎖血，有限步三消收紅蘋果；成功解鎖，仍須扣到 0 才接深淵 |
| 深淵巨口 | 840／1050 | 20% 鎖血食道逃亡；到出口留下 10%，最終爆發抓窗口反攻至真正 0 |
| 收尾 | 三條血真正歸零 | 深淵敗北→半透明胃本體→暴食結算 |

總 HP 2100／2450 依附件固定值；不再額外乘「減 30%」。第一／第二條血 50% 改外貌，五階段輪廓獨立，屬細節試作。Boss HUD 只有名字及比例條，不显示數字或型態編號，不提前露後續形象。

| 玩法 | Normal／Hard 試作目標 | 操作與判定 |
| --- | --- | --- |
| 貪吃蛇 | 45 秒、10／12 果實 | 方向轉向，原粉紅心為蛇頭；撞牆或自身失敗，不能直接反轉 |
| 食物三消 | 55 秒、36／48 清除、22 步 | 點相鄰兩格或方向＋空白選格；至少三同款才消除；無效交換不耗步，連鎖及無解洗牌 |
| 合成西瓜 | 90 秒、112／160 分 | 左右瞄準／拖動，空白或放手落果；真重力、碰撞及同款合成，八種大小；C 三次換果，堆頂失敗 |
| 割繩餵糖 | 65 秒、三餐 | 拖劃割真繩線，或左右選繩／空白割；重力與擺動、後兩題障礙，糖落入怪獸才成功；C 重擺不重置總時計 |
| 切食物 | 40 秒、20／24 果實 | 拖劃切穿果實；鍵盤方向移游標＋空白切；炸彈扣 8、漏三果扣 3，不能重複刷同一果 |
| 飢餓引力 | 16 秒 | 大嘴周期吸向自身，反向走或近桌腿空白抓住，C 放手；吸入扣 22 |
| 反芻彈射 | 16 秒 | 碎屑實際反彈，碰到扣 6，第五次反彈消失；近金糖空白反攻 |
| 啃食地板 | 16 秒 | 紅框預警一秒後變洞，跌落扣 12、安全重生；中路與底路永遠連通，近金糖反攻 |
| 三消處決 | 24／20 步、18／22 紅蘋果 | 沒有時間限制；耗盡步數而未達標扣 **80 HP**，兩難度同值；失敗後保留鎖血，20 秒戰鬥時間後重試 |
| 食道逃亡 | 60／50 秒、出口 100% | 左右避食物／洞，空白跳；成功當幀先停止碰撞，失敗扣 60，20 秒後重試 |
| 最終爆發 | 無時間限制、打掉餘血 | 避反彈碎屑，巨口張開時近金糖空白反攻 32；關閉時不接受反攻，不自動清血 |

普通攻擊的吸力、反彈速度、啃食頻率逐階增加，Hard 再加強；第三階段仍保留連通安全走道。這個方向已獲使用者選定，具體倍率、時計、目標、反攻值與回血仍屬可調試作。

Bridge 使用原 `logic.mjs` 及原繪圖、保留／下一塊／落點／特殊方塊、150／35／70 ms 連移。消行才造成傷害：每行 28、連擊最多加 12；到時不自動扣 Boss。原獎勵觸發本關遊戲，Sand 獎勵映射至水果合成，沒有實作舊 Sandtrix。一般遊戲進度、完成、消行、變身與原真貓魚乾有回血；Normal 基數，Hard 半量最低 1。三消、割繩與水果合成的最後 3／2／1 秒及逾時用共用柔和倒數；有限步處決不假設另一個時計。

第一血五款的「已玩」包括完整成功或失敗，中途退出不算；8% 鎖血只是保證五款都能遇到的試作門檻，沒有把失敗當成功。階段過場只留「繼續」、4 秒自接，停止戰鬥／題目／重試時計。一般回合結果 1.6 秒自接；最終勝敗才提供返回／重試。

## 驗證、試作與限制

- 534 項 Node 回歸通過：502 原有項目及 32 本關項目；含三血／鎖血／重試／最後真扣血、五款機制、500 種穩定可解三消盤、30 種實際可完成處決及攻擊物理。
- Chromium 四比例 390×844、844×390、1024×768、1280×900 ×32 入口，共 128 組。盤面≥140 px、控制≥44 px、貓清楚且不壓盤面／按鈕，設定捲到返回，切語言不重開，存檔不變；0 pageerror／HTTP 錯誤。兩张胃修正另重查八組裁切。
- 真鍵盤／滑鼠以固定 RNG 和模擬時計完成蛇 10、三消 39、處決 18 蘋果、割繩三餐、合成 114、切果 20；未設定 HP、分數、盤面或完成旗標。屬各獨立回合驗證。
- 完整階段銜接使用明示的近敗北 fixture；三消處決、逃亡到真 100% 與最終反攻至真 0 以實際輸入完成。另驗割繩逾時／重試。**不當成自然完整 Boss 通關。**
- 既有四位 Boss 與卡帶程式／正式入口 diff 為零；原存檔保留。回歸有 Node 覆蓋，沒有重新聲稱所有舊关硬體畫面測試。
- 四比例／觸控／時計為 Chromium 模擬；沒有實體 iPad、Safari 或低階電腦驗證。15 分鐘是設計目標，尚未完成人類整場計時和平衡確認。

益智最後 3／2／1 及逾時共四聲實際 WebAudio 啟動，暫停停止時計／聲音、靜音無新增提示均通過；近倒數時計是明示 fixture。可攜單檔本機 HTTP 實際下載 SHA 相符，只請求 HTML、零外部圖／字型／模組，CDP 真觸控落果正常。環境 Chrome 的 file:// 被管理政策阻擋，沒有繞過或宣稱直接開檔驗證成功。檔案本身完整內嵌，亦提供可本機 HTTP 啟動的資料夾包。冷快取選擇頁 2,264,448 bytes 是本機 Python HTTP、未傳輸壓縮、非 Pages CDN。
