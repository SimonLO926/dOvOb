# 色慾 r9：貓咪、舞步、Hard與未來PR壓縮

使用者要求：貓咪比之前少動作、位置難看見，打回一點；舞步hold仍Miss；約會多後Hard扣血偏少，略提高難度；正式推送／PR那次要壓縮令遊戲輕量。沒有批准發布、推送、PR或第四Boss正式整合。

來源：原 `crazy-view.mjs::drawMischiefCat` 會對照片呼吸、揮爪、受擊壓低、勝利舉爪；Lust r8僅靜態img＋魚乾發光。r9把原照片／局部爪姿勢邏輯隔離到 `lust/cat.mjs`，避免引入前三Boss整個renderer與素材。沒有生成新貓圖、沒有新增提示詞，原WebP SHA不變。恢復的是演出，沒有照搬前三Boss隨機打玩家／砸盤面等專屬数值。貓仍每18秒送魚乾，Normal10／Hard5HP；消行／約會命中／受擊對應不同姿勢，待機少量呼吸和揮爪。

尺寸試作：手機124、直向觸控平板136、橫向觸控130、桌面146螢幕像素；原圖保持比例與毛邊。手机預留較高的既有操作區上方空隙，盤面HP仍底部、原控件排位保留；桌面移到盤面左下側空位，育成／滿頁插圖同樣保留。減少動態靜止照片，暫停凍結照片姿勢，不遮盤面／HP／控件。

舞步根因：長拍原來只接受125／175ms判定窗內新的keydown；提早按住到拍點没有再發按下，因此一直Miss。原提示進度又把拍點與持續長拍共用一條金色滿條，沒有把判定窗顯示出來；點中央「長拍方向」卡還按x坐標映射另一按鍵。r9長拍可提前最多1250ms預備，真正到拍點才計算420ms持續；提早放手／按錯方向仍失敗。長拍開始和完成給正常節奏提示，不再用Miss低音；連擊／姿勢照樣累計。拍點條綠區與Normal175／Hard125ms真判定共用，拍點設在條85%，晚點仍能看出已過綠區；開始hold後換金色持續條。中央提示卡依顯示方向操作，底部四按鍵仍←↑空白→，只點人物不發亂鍵。按鈕以pointer capture維持拖出後長按，pointerup/cancel/lost capture、設定／失焦才釋放。

Hard試作：所有實際受傷base×1.25四捨五入，例如炸彈7→9、通常小遊戲未完成12→15、電眼處決未完成35→44、Bridge頂出原Hard16→20；Normal不改。Hard琴鍵／舞步每兩次成功恢復1HP，原為每次1；其他成功、消行、過場和貓回血保留Hard50%。沒有縮Boss血、刪五款約會門檻、借前三Boss專屬挑戰數值；傷害與節奏回血頻率為自行合理微調，並非使用者指定確切數字。
