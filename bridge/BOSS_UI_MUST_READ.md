# Boss 畫面與操作必讀規範

適用：**貪婪、傲慢的所有型態、普通回合、特殊玩法、過場及結算**；下一個七大罪 Boss 沿用共用規則。整理基準為正式版 **1.2.26**，接線與畫面狀態更新至 **1.2.33**。

**1.2.31：使用者已明確要求「接好他」，嫉妒正式開放。傲慢既有通關紀錄直接解鎖嫉妒；正式入口與獨立 Preview 分開。宣傳片 agent 使用 sessionStorage 暫時解鎖已推出的三位 Boss，不能偽造／覆寫通關旗標；拍攝戰鬥不寫正式紀錄。** 詳見 [接線與拍攝指南](FILMING_GUIDE.md)。

這是使用者已確認要求的整理，不是新的難度調整。修改前先讀本檔及 [CRAZY_MUST_READ.md](CRAZY_MUST_READ.md)。使用者最新明確要求優先；發現實作偏離時先記錄問題，不把既有錯誤當成設計規範。早期 `CRAZY.md`、試玩說明及來源更新包只作歷史參考。

**每個新 Boss：先交付試玩 → 按使用者回饋修改 → 使用者明確確認本關「OK」→ 才推送正式整合、建立及合併 PR（pull）。** 前一個 Boss 的批准、圖片選定或自動測試通過，都不能代替本關試玩確認。詳見 [每個新 Boss 的交付流程](CRAZY_MUST_READ.md#每個新-boss-的交付流程)。

## 0. 原版 UI 是固定基準

**UI 維持原版，只改 Boss 主題。** 沿用貪婪／傲慢已確認的版面、玩家血量位置、遊戲框、保留／下一個、原方塊與落點、按鈕排位及輸入；可替換背景、本體、主題色與本關元素。除使用者明確要求的新玩法資訊或本檔已記錄的例外，不因製作新 Boss 而另設 HUD、移動血量、重排按鈕或換方塊造型。

嫉妒新增「偷窺之窗／眼睛收藏室」也沿用這項規則：擦拭、物件與解謎面板只在原小遊戲區，底部 HP、血條及左右／主副動作鍵不移動。觸控擦除必須是局部連續筆劃，放手、取消、離框或退出菜單後斷開，不能把兩次觸碰之間整段誤擦除。收藏室提示／密碼／眼紋不可蓋住操作物件；詳盡流程見 [嫉妒試玩](ENVY_PREVIEW.md)。

新增效果說明要用本玩法已有的空白說明區，保留原血條和控制位置；不能把說明堆到框旁、壓在圖片或可玩物件上。

## 1. 畫面區域與遊戲框

畫面分為：獨立場景背景、包框的 Boss 本體、HUD、可玩區、簡短提示／回饋、觸控操作區。每個區域有自己的空間，不能以縮小遊戲框來容納冗長說明。

- Boss 本體要**包圍遊戲框**：包含頭部、肩頸或鏡核連接、兩側身體／披風／鏡翼及握框的手／爪。不能只放頂部立繪、皇冠或菱形側欄。
- 頭部貼實框體，保持威嚴及可辨識輪廓；裝飾不得蓋住血條、方塊、玩家、彈幕、攻擊預告、落腳點或可點物件。
- 戰鬥頭部與貪婪／傲慢本體使用一致的像素輪廓、色塊、階梯邊緣及高光；不能把細緻概念立繪裁成人頭貼在像素包框上。概念圖仍保留作立繪／設定參考。
- **嫉妒 r10 結算例外**：敗北／本體揭露／結算插圖填滿整個可見視窗，原比例裁切，獨立於遊戲框；標題及按鈕可讀可點，戰鬥暫停。原真貓使用螢幕尺寸的獨立圖層，不隨盤面縮小；退出過場恢復原 UI。詳見本檔末「嫉妒 r10」。
- 玩家始終使用原有粉紅像素心心，受擊也使用同一圖案。貓保留，作為七大罪後「貓之試煉」的伏筆；貓與其提示／特效也須檢查遮擋。
- 背景是**獨立場景**，不是把 Boss 概念圖鋪滿畫面。立繪用於選擇、開場、變身、敗北或通關過場。
- Bridge／Sand 保留完整方塊盤、保留與下一個預覽，方塊及球等比例繪製；不得拉伸、裁掉底部或讓觸控座標偏移。
- 新 Boss 的基本 HUD／Bridge 排位沿用原版，只改本關主題。Bridge 玩家 HP 在底部 `height-38`、血條 `x=24,y=height-25,w=232,h=6`；保留標題 `(40,37)`、預覽 `(26,53)`；下一個標題 `(240,37)`、三塊預覽 `(226,49+i×21)`。不得移成上方玩家 HP、棋盤旁卡盒或自創方塊造型。方塊顏色、圓角、落點虛影、特殊標記沿用主遊戲。
- 每個玩法只畫一套符合其格距的格線；Bridge 的共用格邊只畫一次，背景橫線／裝飾格線不能疊入方格盤。盤底狀態與提示放在邊框之外，文字字框也不能碰到最後一行。
- UI 縮放只改顯示比例；碰撞、射線、落點及命中範圍仍對應實際遊戲坐標。裝飾超出命中區時必須仍能辨認中央可命中的本體，不能讓玩家誤判。
- **傲慢逃塔例外**：普通遊戲框，隱藏 Boss 包框、頭部、Boss 血條及外框貓裝飾；保留巴別塔場景、玩家及逃塔所需資訊。

## 2. 兩位 Boss 的主題與型態

| 項目 | 貪婪 | 傲慢 |
| --- | --- | --- |
| 場景元素 | 賭場、金幣、牌、麻將、777 等既有元素 | 紫金鏡宮、王冠、鏡面、碎鏡與巴別塔；不混用賭場元素 |
| 戰鬥本體 | 莊家頭部、王袍、肩膀、雙臂、握框手；後續本體保留金色金庫特色 | 鏡宮之王包框本體；鏡之化身有鏡核頭部、鏡翼及碎鏡爪 |
| 型態辨識 | 各自名稱及外貌，不在玩家介面標「型態 1／型態 2」 | 同樣用各自名稱；三鏡、兩鏡、紅鏡均有不同輪廓與頭部，不能只換色 |
| 低血量挑戰 | 第二條血 20%：BGM、鎖血、金庫挑戰 | 國王 20%：鏡中對決；鏡之化身 50%：巴別塔、剩兩鏡；15%：一面狂暴紅鏡及彈幕決戰 |
| 勝利／結算 | 貪婪自己的敗北圖及主題 | 國王、鏡之化身各有敗北圖；最後使用崩塌後塔的廢墟與前景碎鏡 |

- 國王的「王之蔑視」只有原有雙眼；不能預先露出第二條血的三鏡。鏡之化身才按剩餘鏡數從不同位置及方向發射。
- 紅鏡彈幕對手為稍大的紅色王冠鏡子、金色破冠及刃翼；鏡面使用反光、裂紋及王冠倒影，不畫眼睛或瞳孔；中央 52×54 命中區保留，裝飾不壓住血條或玩家活動區。
- 介面可顯示目前已發生的鏡數／狂暴狀態；不提前在普通 HUD 劇透後續型態、外貌或結算圖。
- 用「巴別塔」「爬塔」「逃離傲慢之塔」等正式名稱，不在介面顯示參考遊戲的名字。

## 3. 血量、血條與倒數

- **共用益智倒數音（貪婪／傲慢／嫉妒及後續 Boss）**：最後 3／2／1 秒各一聲輕短「嘟」，到時且未完成接「嘟——」。沿用音效開關／音量，與 BGM 音量分開；暫停不走時、不預排或補播、不每幀重複響。提前完成（含最後一窗已擦開的展示）停止提示；過場／結算不響。這是小音效，不能代替正式 BGM，也不新增提示框、搬動 HUD 或按鈕。
- 跟隨**玩家實際要完成的題目時限**：貪婪紙牌／麻將用每組配對的短計時，冷卻／貓阻擋時該計時停下；新題已在最後 3 秒內，首個計時更新只提示當前秒。傲慢萬花筒／鏡中鏡只跟解題時段，不在已解出後的反攻／休息時段響。扣時跨過多秒只提示當前邊界，不連續補播。
- 適用清單：貪婪**紙牌配對、麻將配對**；傲慢**鏡像配對、加冕抉擇、宮殿連連看、碎鏡拼圖、真假鏡、鏡面迷宮、鏡像萬花筒、鏡中鏡**；嫉妒 r11 清單見 [ENVY_PREVIEW.md](ENVY_PREVIEW.md)。Bridge／Sand、賭機、戰鬥／三軌音樂、紅鏡彈幕、金庫跑酷、爬塔／巴別塔及逃塔不套用這組益智提示。新增同類解謎關沿用此規則，不能對所有模式一律加倒數。
- **倒數要柔和，但開著 BGM 仍可聽見。** 三位 Boss 共用 [puzzle-countdown.mjs](puzzle-countdown.mjs) 的聲音及包絡：580 Hz 正弦波，短音 120 ms／峰值 .065、尾音 360 ms／峰值 .075，再乘使用者音效音量；15 ms 平滑起音、短暫維持及柔和收尾。舊 .010／.013 峰值及立即衰減容易被 BGM 蓋過，不能還原。貪婪／傲慢由 [audio.mjs](audio.mjs) 播放，嫉妒倒數模組重用同一 helper。不可用大聲方波／一般受擊音替代；驗收需同時啟用 BGM，不只檢查事件產生。

| 資訊 | 顯示規則 |
| --- | --- |
| Boss 主血量 | 顯示**比例血條**，不顯示 HP 數字、`目前／總量`或懸浮數值 |
| 玩家血量 | 可顯示玩家 HP 數字／比例血條；Pride 特殊玩法由自己的 HUD 顯示，不重複疊上通用 HUD |
| 鎖血 | 可用鎖住／防禦的簡短文字或符號表達；血條與實際鎖血狀態一致 |
| 紅鏡回合血條 | 顯示獨立比例血條，不顯示數字；與上方 Boss 主血條分開，不能混為同一條 |
| 紅鏡時間 | **不顯示剩餘秒數、還需幾秒或倒數**；只顯示「紅鏡鎖血」／「擊破紅鏡」等必要狀態 |
| 逃塔 | 顯示樓層進度、剩餘機會及必要狀態，不顯示已敗北 Boss 的 HP |
| 難度 | 只寫 Normal／Hard，不加「回血較多／較少」說明 |

供實作核對的內部數值：貪婪 900／1200；傲慢國王 1000、鏡之化身 Normal 1200／Hard 1600；紅鏡回合 Normal 680／Hard 1800。**這些數字不等於允許寫到 Boss HUD。**

紅鏡必須同時滿足至少 30 秒及清空獨立血條才解鎖；30 秒前最後 1 HP 鎖住。不能因為隱藏倒數就移除時間條件，也不能將解鎖誤當 Boss 最終敗北。

血條、狀態文字及頭部使用各自區域。Pride 主血條目前在 Bridge y=116、特殊玩法 y=84；紅鏡獨立血條在世界 y=178。這些坐標要連同縮放檢查，不能直接覆蓋另一個 HUD。

## 4. 控制按鈕與輸入

- 所有 Boss 沿用主遊戲的觸控自動／開／關，共用 touch-controls.mjs。自動依 `(pointer: coarse)` 或 `(hover: none)` 判斷，不能單憑視窗寬度或新 Boss 試玩頁固定顯示觸控鍵。電腦滑鼠／鍵盤隱藏觸控區後重新分配空間，保留原 HP／Bridge 坐標及可見原真貓；手機／iPad保留原按鈕排位。手動開／關仍優先，正式與獨立試玩均須一致。

| 功能 | 鍵盤 | 手機／iPad |
| --- | --- | --- |
| 左右移動／選擇 | 左／右方向鍵 | **左右按鈕放螢幕左側**，沿用 Bridge 排位 |
| 主動作 | 空白鍵，沿用既有主動作路由 | 原下落鍵位置，標示本回合功能，如集火、封鏡、下降 |
| 副動作 | C／Shift，沿用既有保留路由 | 原保留鍵位置；本回合沒有副動作則停用，不另添 A／B |
| Bridge 旋轉 | ↑／X，Z 反向旋轉 | 原旋轉按鈕；特殊玩法按已實作路由改成上移等功能 |
| 上／下移動 | 沿用本回合的方向鍵對應 | 保留原操作位置，按模式啟用，不偷偷改到左右按鈕上 |
| 直接操作 | 滑鼠點選／拖曳 | 點選／拖曳遊戲框，與顯示物件位置一致 |

- A／B 只可出現在歷史稿的描述中，不能恢復為玩家必須使用的確認鍵或新按鈕。需要主動確認時沿用空白鍵／原主動作。
- 每回合的按鈕文字、啟用狀態、教學及鍵盤／觸控路由一致。不能標「集火」卻觸發下降，或讓無副動作的按鈕仍消耗資源。
- 支援移動與主動作同時按、短點及長按；退出、失焦、取消觸控和換回合時釋放按住狀態，避免卡鍵。
- Bridge 手感也沿用原版：共用 `bridge-controls.mjs` 的 `BRIDGE_REPEAT`（鍵盤首次 150 ms、後續 35 ms，觸控每 70 ms）；每次按下從零計時，最後按下的方向控制連移，鬆手／取消／滑出按鈕立即停。不得用持續累積的閒置計時器讓短按多走一格，或為新 Boss 另寫固定左右連移節奏。
- 紅鏡自動射擊，主動作集火、副動作精準慢移；不能另外要求玩家持續按發射鍵。
- **碎鏡風暴例外**：三個直行，鍵盤左／空白鍵／右對應左／中／右；手機顯示左／中／右三個大鍵，不沿用會令人誤解的保留／下落標籤。
- 碎鏡風暴評價使用 best／good／damage，顯示位置不遮住下一顆音符或判定線。
- 主選單及遊戲內菜單提供「控制按鈕說明」，只列簡短按鍵與功能對照，觸控沿用相同功能，小遊戲以當前按鈕名稱為準。不要加入冗長教學或搬到遊戲框旁擠壓空間；手機／iPad 仍能捲到返回。
- Crazy 選單目前不暫停一般戰鬥；不能因為選單名稱或圖示而宣稱戰鬥已暫停。危險特效設定與這項規則分開處理。

## 5. 文字不能重疊或壓住遊戲

- 操作中的畫面只留短標題、必要狀態、目標及操作提示；詳盡玩法放教學／說明文件，不能讓左右說明把遊戲框擠細。
- 每段文字只有一個繪製來源。Pride 小遊戲／攻擊有自己的 HUD，外層不能再疊上同一區域的通用標題、倒數、提示或玩家血量。
- 文字不能跨進可玩區、血條、頭部、觸控按鈕或其他文字的實際字框。中英、數字、標點及後備語言都要檢查；不能只量文字基線。
- 過長時先縮短內容、安排有空間的換行或隱藏次要資訊；不能靠把字縮到看不清、裁切、蓋住遊戲來通過。
- 提示、即時回饋和 Warning 同時出現時也必須各有位置。若同一位置有多種訊息，明確選一個顯示，不同時畫上去。
- 普通成功回饋不蓋住仍在進行的遊戲，不阻止避彈或操作。完整故事卡只在專屬過場顯示，並與戰鬥計時／傷害停止狀態一致。

### 抽卡與效果說明

- 卡圖要精緻、主體清楚，但不堆滿背景裝飾。每張卡使用可辨識的不同顏色主題，避免大面積綠色底圖與嫉妒綠色場景撞色；綠色可留在龍本體或少量寶石。
- 使用者已要求抽到的卡幾乎佔滿遊戲框：專用抽卡回合可將卡框放大至原可玩區的約 95% 寬度，牌名與效果放在卡內下方獨立文字區。此例外不移動共用標題、底部玩家 HP／血條、確認提示或控制鍵，也不能套用為戰鬥遮罩。嫉妒 r6 卡框為 `x=18,y=154,w=244,h=344`；效果基線 `458/473/488`，確認提示 `509`，玩家 HP `522`。
- 塔羅正位使用朝上的正面卡圖；逆位使用同一正面卡圖旋轉 **180°**，不是左右鏡像、背面或另外換圖。牌名、「正位／逆位」及效果文字保持朝上可讀。
- 塔羅及嫉妒秘藏揭示後、確認收牌前，持續顯示這張牌的實際效果；不能只顯示稀有度、牌名或短暫通知。效果資料必須與結算共用來源，Hard 回復值按實際計算，不只顯示 Normal 基數。
- 秘藏 SR／SAR 的代價與增益都寫出：下次攻擊自己受傷 +50%，同回合反攻 +30%。稀有演出及閃光限於圖像區，不蓋住牌名、效果、血條或按鈕。

## 6. 特效、可讀性與選中狀態

- **全部 Boss 的扣血回饋**：每次真正接受傷害，由遊戲區發出短促、明亮的攻擊軌跡，飛到遊戲框頂部當前頭部，再顯示局部命中火花／亮框。貪婪、傲慢、嫉妒及後續 Boss 共用 [combat-effects.mjs](combat-effects.mjs)；鎖血擋下、拒絕或零傷害不播放，變身／回復不誤當扣血。鍵盤、觸控、更新、貓及小遊戲結算都要覆蓋；傲慢紅鏡的獨立回合血量也要回饋。
- 玩家受擊用清楚的紅色角框及心心附近局部提示，仍用原像素心心；不能用不透明全盤紅幕，亦不能擋住敵彈、落點、題目、血條、貓或按鈕。特效圖層透明且不攔截點擊，不改版面及移速。回血與受傷同幀仍要根據真實傷害事件給出受擊回饋。
- 攻擊起點及頭部命中點依當前玩法坐標映射；Bridge／Sand 和特殊玩法頭部位置不同，手機縮放後仍須命中頭部。特效使用280的邏輯寬度，不能混用主 Canvas 的 DPR／CSS backing尺寸；傲慢短橫屏的可見邏輯高度也須跟原 Canvas 變換一致，僅對比兩層的 CSS矩形相同不足以證明命中正確。傲慢逃塔、嫉妒逃離／捕捉等沒有 Boss 頭部的普通框不憑空畫頭部攻擊。敗北／全頁過場清掉舊軌跡，不在下一型態補播；最後一擊可由敗北插圖接手。
- Warning 模式的受擊提示不抖動；抖動只沿用原本抖動模式。減少動態時以短暫靜態頭部／玩家角框顯示，停用飛行軌跡、擴散與閃爍。暫停不推進軌跡、換關重設追蹤，最多保留有限數量的短軌跡，不堆滿遊戲區。
- 關卡選擇頁的鎖頭與解鎖狀態一致：未解鎖顯示鎖頭；解鎖後隱藏鎖頭、顯示本罪徽記，通關後也不恢復鎖頭。SVG 圖示以 `hidden` 屬性切換，不能只指定 HTML 的 `.hidden` 屬性。
- 正式選關預覽使用角色融入完整主題背景的概念圖，像貪婪／傲慢；不能用透明頭部圖集的小裁片加純色底代替。嫉妒1.2.32使用帶幽林／鄰居窗戶場景的窺視之子概念圖，不能提前展示多眼龍／巨瞳／綠蟲。
- 點選已解鎖 Boss 先顯示該 Boss 的預覽圖片與簡短介紹，再按「挑戰」才開始正式關卡；傲慢使用國王主題，不顯示尚未遭遇的鏡之化身。這是正式關卡選擇預覽，不是獨立測試 Preview 的入口。手機預覽與挑戰按鈕須可捲到、可點。
- 完整通關後，預覽背景解鎖該 Boss 後續型態的剪影：貪婪為噬金莊家、傲慢為鏡之化身；未通關不可顯示。傲慢沿用貪婪的國王立繪與後方剪影構圖，不混用另一罪的圖片。
- 危險特效保留兩個選項：**抖動**與**不抖動的紅色 Warning**。選 Warning 時不加入畫面抖動；抖動模式保留既有危險效果，不能藉換關重置使用者選擇。
- 遵守「減少動態效果」；背景浮動、光暈脈動及裝飾動畫需減少或停止，但保留能判斷危險的靜態提示。
- 選中／焦點用高對比雙框或角框，手機也要明顯；不能用整片光罩蓋住牌、鏡子或拼圖內容。
- 彈幕、傷害預告及落點要比背景和裝飾更容易辨識。粒子不能掩蓋玩家心心、敵彈、出口或封鏡時機。

- 塔的平台畫法與實際支撐寬度一致；用原有巴別塔石砌、拱窗、刻紋及金飾的平面長方形，不改成立體長方體。

## 9. 手機、iPad 與桌面比例

- 至少檢查 **390×844 手機直向、844×390 手機橫向、1024×768 iPad、1280×900 桌面**；若改斷點，也檢查其附近及更窄的畫面。
- 同時容納遊戲框、必要 HUD、選單及完整控制區；不得裁掉遊戲底部、主動作或返回按鈕。橫向 Bridge 現有參考寬約 165 螢幕像素，不能為塞說明再明顯縮小。
- 既有檢查使用遊戲框寬至少 140 螢幕像素作門檻；這**不代表字、彈幕或點選物件一定夠大**，仍須看截圖及實際操作。
- 使用實際可見視窗高度，處理瀏覽器工具列、旋轉及視窗縮放；調整後仍須測點選座標。
