```js

```

```js
sessionStorage.removeItem('bridge-filming-unlock');
location.reload();
```

Playwright JavaScript 範例，先進入遊戲同源網站再設定：

```js
await page.goto('https://simonlo926.github.io/dOvOb/bridge/');
```
