# Crazy：第一場 Boss 戰原型

Crazy 與 Marathon、40 行競速同在 Bridge 的選單。Marathon 保留既有規則。
滑鼠移入或鍵盤聚焦 Crazy 即預覽背景；觸控第一次點選預覽，第二次進場。

## 角色

- 首個 Boss 為「貪婪・狂宴莊家」：像素轉輪面具、王冠與三階段攻擊，賭博玩法圍繞貪婪主題。七大罪暫留作後續方向。
- 參考照片的虎斑白胸、金鈴鐺貓是隨機搗蛋角色，**不是 Boss**。
  貓使用照片去背及輕微調色的透明素材，先探頭警告 1.2 秒。
  事件機率：回血 25%（+8 HP）、抓 Boss 20%（18 傷害，受每回合上限保護）、
  抓玩家 15%（−6 HP，可在預告時左右躲避）、局部打碎方塊 25%、普通搗蛋 15%。
  沒有方塊的玩法會把打碎事件改為抓 Boss；貓破壞不觸發方塊的炸彈及懲罰。

## 戰鬥規則

玩家 100 HP，莊家 900 HP。Boss 剩餘 600 / 300 HP 時進入第二 / 第三階段，
玩家各回復 12 HP。HP 不超過 100，歸零結束；Boss 歸零勝利。
每場上限八分鐘，到時莊家收桌；實際過關速度取決於反擊效率，平衡仍可依實玩調整。

戰鬥從 Bridge 開始，之後每三個回合回到 Bridge，中間連接兩個特殊玩法。
每回合依階段為 20 / 18 / 16 秒，Boss 每回合最多受傷 50 / 55 / 60 HP；打滿後進入防禦，仍可打斷攻擊及回血，避免首回合就被快速消行擊敗。
抽牌組安排特殊玩法，避免直接重複及連續困難段。
進場沒有四秒準備倒數。切換會清除長按狀態，給予 0.5 秒受傷與誤發保護。
玩法切換顯示金色爆線、莊家出招橫幅和大字模式名，800 毫秒內淡出，戰鬥計時不中斷。
減少動態設定保留靜態提示，停用爆線及轉輪滾動。

每回合開始約 4.5 秒後，莊家預告攻擊；玩家在 3.5 秒內命中可打斷攻擊。
沒有反擊則依階段受傷 6 / 8 / 10 HP。整回合沒有命中，另扣 8 HP。
Bridge 堵頂扣 20 HP 並清除上方八行，仍可救回；球類漏球扣 12 HP 並直接接下一玩法。
暫停、離開頁面或切到背景都停止戰鬥計時。減少動態設定會停用背景與角色浮動動畫。

## 小遊戲

| 玩法 | 操作與目標 |
| --- | --- |
| Bridge | 消行攻擊，連擊回血；左右移動、X / Z 旋轉、C 保留、空白鍵落下 |
| Sandtrix | 同色連通左右兩邊，僅消除相連沙粒；返回時按剩餘沙粒面積轉回方塊 |
| 角子機 | 空白鍵／行動逐輪停止，配成兩個或三個相同圖案，考驗停轉時機 |
| 老虎機 | 拉桿後三輪依次停下（1.05 秒），期間不可重複操作；中獎後收下領獎回 4 HP，或翻倍（55% 成功，失敗失獎扣 10 HP），最多三次 |
| 拍清哥 | 左右或點畫面瞄準、行動發射；釘板落球入綠槽回血、紫槽攻擊、紅槽受傷 |
| 啤牌 | 限時配出指定數字對子；點牌或左右＋選牌。依階段限時 3 / 2.6 / 2.2 秒，錯牌及超時扣 5 HP |
| 麻將 | 限時配出上方指定牌，每對改變目標並重置倒數；清空三對有額外傷害，C 可重選 |
| 莊家追殺 | 方向鍵或觸屏方向移動，拖曳核心也可。紅色區域預告 700 毫秒後，骨柱／橫向掃射帶著缺口穿過盤面；衝刺無敵 180 毫秒、冷卻 1.4 秒。每無傷存活兩秒反擊 8 點，被擊中扣 6 / 7 / 8 HP |
| Brickout / Pinball / BBTAN | 延用球類控制，打碎方塊攻擊；Pinball 支援長按托球 |

啤牌／麻將連續配對每次額外 +2 傷害，上限 +8；錯牌或超時中斷連擊，貓阻擋操作期間暫停選牌倒數。

Crazy 使用 Marathon 的 Bridge 引擎，保留架塊、連鎖掉落、炸彈、特殊方塊、Fever、垃圾與升階翻盤。
目前方塊、保留及下一個佇列都會跨玩法保留；Sandtrix 進出時先暫存目前方塊、完成沙粒轉換後安全復位。
方塊及球使用等比例顯示。Crazy 與 Marathon 共用沙色表及方塊畫法，下落、旋轉、保留、預覽和落地沙粒顏色一致。球類有自己的挑戰盤面並顯示全部磚塊。
球類打碎垃圾袋只計分，不產生垃圾或垃圾穩固；Bridge 正常消行仍會觸發。
說明文字、盤面與觸控按鈕分為獨立版面區域。
排行榜獨立存入 `bridge-best-crazy`。中英文字已提供，其餘語系使用英文後備文字。

## 後續 Boss 的方向（未實作）

第一場完成後，可沿相同戰鬥介面設計：

- 「鏡面裁判」：以鏡像、方向提示及反擊時機為主。
- 「彈珠機匠」：以球類、拍清哥和移動障礙為主。
- 「牌陣術師」：以牌組、麻將和記憶挑戰為主。

先按第一場的實玩結果調整血量、傷害與回合長度，再决定 Boss 選擇及連戰規則。
