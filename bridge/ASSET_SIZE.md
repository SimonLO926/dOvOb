# Bridge 遊戲容量與壓縮

容量以檔案內容總和計算，MB = 1,000,000 bytes；不含 `.git`、未追蹤的依賴、工作區附件與錄影片。最終精確數字會隨本說明文字略有變動。

## 1.2.32 選關概念圖

新增完整窺視之子概念圖：原PNG為1536×1024、2.92 MB，品質88 WebP為0.43 MB，節省約85%；遊戲只載入WebP。原圖、提示詞及SHA-256保存在source-assets/envy/，仍由Jekyll排除。以下1.2.30容量為歷史核對值，未包含本次新圖及1.2.31正式入口。

這是**靜態部署素材與程式的內容總量，不是首次開啟的下載量**。全網站數值按將推送的來源檔案計算；Jekyll 渲染 Markdown 後的實際部署產物會略有不同。未追蹤的 `dynamic-answer-book/node_modules/` 不計入，也不應加入本次提交。

- 嫉妒十張採用來源 PNG 共 30.40 MB，對應十張保存的 WebP 共 7.11 MB；WebP 保持來源尺寸。兩張未採用 PNG 草稿也保存，全部本關 PNG 共 35.09 MB。早期頭部概念及塔羅 WebP 是歷史參考，不是現行戰鬥頭部；實際 Preview 畫面按 `envy/art.mjs` 的清單載入。
- 嫉妒七首原始音樂共 22.44 MB，網站副本共 11.23 MB，節省 11.21 MB。網站副本使用 128 kbps、44.1 kHz、立體聲 MP3，七首均保留完整歌曲；逐首容器時長只增加約 0.026 秒編碼填補，未裁剪第七首完整 1:44 歌曲。
- [音樂來源清單](../source-assets/envy/music/sources.json) 同時記錄原檔及各網站副本的 SHA-256、容量、時長及編碼資訊。原始 MP3、採用 PNG、未採用草稿、提示詞與原設計均保存於 `source-assets/envy/`，`_config.yml` 排除整個 `source-assets/`，不把重複原檔部署到 GitHub Pages。
- 網站獨立試玩網址為 `bridge/envy-preview.html`，與其他 Boss 共用既有素材／程式。主遊戲沒有新增嫉妒試玩入口，本試玩不寫正式通關、解鎖、紀錄或設定存檔；大型離線單檔、ZIP、錄影與工作區測試產物不加入網站。

容量檢查不代表所有舊畫面已通過新版比例驗收。貪婪既有橫向紙牌配對框較窄，尚未在本次改動中調整，不能宣稱所有 Boss 在各比例的遊戲框均達 140 螢幕像素。

## 壓縮結果

- 傲慢七張 PNG 原始圖共 16.7 MB，正式七張 WebP 共 3.83 MB，保留原始尺寸。
- 傲慢八首音樂由 35.0 MB 降至 17.5 MB，使用 128 kbps 立體聲 MP3；全部保留完整時長，逐首檢查與原檔長度差少於 0.15 秒。
- 貪婪、貓的四張大圖與角色精靈改用 WebP；角色精靈為無損，已逐像素檢查可見 RGBA 與 PNG 一致。
- 原始 PNG／MP3 共約 63.9 MB，保存於 `source-assets/pride/` 及 `source-assets/greed/`。各來源清單記錄 SHA-256，確認逐位元保留。`_config.yml` 排除此目錄，GitHub Pages 不部署這些重複原檔。
- 不把內嵌完整音樂的大型離線 HTML 再放進 GitHub；網站 Preview 共用正式素材，獨立網址為 `bridge/pride-preview.html`，主遊戲不設入口。離線單檔可由既有建置工具產生。

保留原始素材會增加 GitHub 原始檔容量；上表的儲存庫原始檔容量不是 Git 的壓縮傳輸量，也不是玩家首次開啟網頁的下載量。
